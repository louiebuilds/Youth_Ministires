# Release Notes

## v0.15.0 — Milestone 14: Scheduling

**Release Date:** August 11, 2026  
**Status:** Released

Version 0.15.0 adds secure internal scheduling for ministry volunteers.
Authorized managers can create schedules, locations, required positions,
assignments, and recurring rotations; detect and intentionally override
conflicts; publish schedules; and retain cancellation and rotation history.

Volunteers receive a My Schedule view containing only their own published
responsibilities and locations. Parents and anonymous users do not receive
Scheduling access.

Scheduling tables remain deny-by-default, protected RPCs enforce authorization
server-side, conflict override reasons and audit evidence are retained, and
historical generated schedules are not rewritten. Existing event references
are optional and the calendar foundation is provider-independent.

Acceptance corrections cover successful `void` RPC handling, assignment
listing, proper volunteer names, and protected unattached-location listing.
Malformed synthetic timestamps observed during testing were test-input errors.

All required automated verification and all 23 Product Owner acceptance checks
passed.

**Milestone 14 — Scheduling: Complete**
