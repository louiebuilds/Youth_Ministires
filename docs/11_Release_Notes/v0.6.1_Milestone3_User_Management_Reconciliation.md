# v0.6.1 — Milestone 3 User Management Reconciliation

**Released:** 2026-07-24
**Roadmap milestone:** 3 — Authentication & User Management

## Added

- Self-service profile view and display-name editing
- Authenticated password changes with secure sign-out
- Administrator-only existing-account directory and search
- Existing-account display-name, permanent-role, and lifecycle management
- Database-generated audit events for profile and account changes
- Administrator self-demotion and self-deactivation protection
- Synthetic-data verification and privacy-safe acceptance checks

## Security

Account administration is restricted to Platform Administrators. Family
accounts receive Not Found for the account-management route. Direct
authenticated profile mutation grants were removed, and database functions
reauthorize and validate every mutation.

## Approved Boundaries

The five-role model, separate administrative and family accounts, and Version 1
student-login exclusion remain unchanged. Auth identity creation and
administrator-triggered recovery emails await a separately approved privileged
identity-provider gateway.

## Verification

All automated and production-build checks passed. Connected Supabase acceptance
returned eight successful checks, and Product Owner browser acceptance passed
with both family and administrator accounts.

Milestone 6 was not started.
