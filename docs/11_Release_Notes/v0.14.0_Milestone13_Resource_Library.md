# Release Notes

## v0.14.0 — Milestone 13: Resource Library

**Release Date:** August 9, 2026  
**Milestone:** 13 — Resource Library  
**Status:** Released

## Overview

Version 0.14.0 introduces the general ministry Resource Library.

The Resource Library provides authorized ministry users with secure access to
approved documents, images, videos, and other supported files while maintaining
private storage, audience-based visibility, protected downloads, and immutable
file version history.

## New Features

### Resource Library

Added a dedicated Resource Library for general ministry materials.

Resources support:

- Title and description
- Category
- Resource type
- Audience
- Lifecycle status
- Current file version
- Search and filtering

Supported resource types include:

- Documents
- Images
- Videos
- Other approved files

### Resource Categories

Authorized managers can:

- Create categories
- Rename categories
- Archive categories

Archived categories are retained for historical purposes.

### Resource Lifecycle

Resources support:

- Draft
- Published
- Archived

Published resources are available only to authorized audiences.

Draft and archived resources remain restricted to authorized ministry
managers.

### Audience-Based Access

Resource visibility is controlled by audience and account authorization.

Supported audiences include:

- Ministry
- Volunteers
- Families
- Authenticated users

Parents and guardians can access published resources authorized for their
audience.

Volunteers can access published resources authorized for their audience.

Anonymous users cannot access the Resource Library.

### Private File Storage

Resource files use private Supabase Storage.

Storage protections include:

- Private bucket access
- Generated object paths
- Approved file types
- File-size validation
- Server-authorized uploads
- Protected downloads
- No public Resource Library storage URLs

### File Versioning

Replacing a resource file creates a new immutable version.

Previous versions are retained rather than overwritten.

Authorized managers can:

- View version history
- Identify the current version
- Record version notes
- Download historical versions

Parents and volunteers do not receive access to historical file versions.

### Protected Downloads

Resource downloads require authorization.

Downloads use short-lived signed access and respect:

- Active account status
- Resource lifecycle
- Resource audience
- Account authorization
- Current versus historical version permissions

Protected download workflows are auditable.

### Resource Search

Authorized users can search and filter resources.

Available filtering includes:

- Search text
- Category
- Resource type

Authorized managers additionally receive management-oriented audience and
lifecycle filtering.

Search results respect authorization and do not intentionally expose
unauthorized resource metadata.

## Security and Privacy

Version 0.14.0 maintains private-by-default Resource Library access.

Security controls include:

- Denied unauthorized direct table access
- Denied unauthorized storage operations
- Role-based Resource Library authorization
- Audience-aware visibility
- Manager-only historical versions
- Immutable file-version metadata
- Protected upload workflows
- Protected download workflows
- Anonymous-access denial

Development and acceptance testing used synthetic files and metadata.

Identifiable photographs or videos of minors remain prohibited.

The Resource Library must not be used to store prohibited confidential
participant, medical, identity, background-check, prayer/care, credential, or
other sensitive information.

## Milestone Boundary

Version 0.14.0 does not introduce:

- Volunteer scheduling
- Permission slips or medical releases
- Custom forms
- Reporting or download analytics
- AI document search or analysis
- Public Resource Library galleries
- Mobile/offline Resource Library functionality

Curriculum-specific resources remain part of the Curriculum feature rather
than being replaced by the general Resource Library.
