# Release Notes — v0.3.0

**Release date:** 2026-07-23  
**Milestone:** 2 — Foundation Infrastructure  
**Status:** Complete

---

## Highlights

Version 0.3.0 establishes the first working application foundation for the
Youth Ministries Platform.

Users can register, confirm an email, sign in, recover a password, access a
protected dashboard, navigate the responsive application shell, and sign out.

---

## Added

- Next.js 16.2.11 foundation configuration
- Supabase SSR integration
- Validated environment configuration and safe `.env.example`
- Authentication session refresh proxy
- Login and registration pages
- Password recovery and reset workflow
- Email confirmation and authentication callback routes
- Protected platform layout
- Authentication-aware root redirect
- Desktop sidebar navigation
- Mobile navigation
- Header and verified account menu
- Server-side sign-out
- Foundation dashboard
- Placeholder pages for all planned foundation navigation destinations
- Shared loading and error feedback components
- Responsive and accessibility behavior
- Milestone test report and implementation journal

---

## Security

- Authentication is checked on the server before protected content renders.
- Privileged environment configuration is marked server-only.
- Registration cannot self-assign an administrative role.
- Callback redirects are restricted to safe internal destinations.
- Authentication errors avoid revealing whether unrelated accounts exist.
- No real Supabase credentials are committed.

---

## Known Foundation Limits

- Dashboard metrics are intentionally not connected to ministry data.
- Role and permission persistence is deferred to database and security
  milestones.
- Navigation visibility is not yet permission-aware.
- Feature routes display foundation placeholders until their implementation
  milestones.
- Audit persistence and Row-Level Security testing require the future database
  schema.
