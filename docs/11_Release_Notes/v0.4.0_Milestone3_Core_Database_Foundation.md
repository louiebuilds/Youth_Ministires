# Release Notes — v0.4.0

**Release date:** 2026-07-23  
**Milestone:** 3 — Core Database Foundation  
**Status:** Complete

---

## Highlights

Version 0.4.0 adds the secure, person-centric database foundation required by
future Youth Ministries Platform features.

---

## Added

- Version-controlled Supabase migration structure
- Permanent primary account roles
- Separate account contexts linked to shared person records
- People, profiles, households, memberships, and students
- Student relationship permissions
- Events and event-scoped volunteer assignments
- Append-only audit-event storage
- Database constraints, indexes, and timestamp triggers
- Existing Auth-user profile backfill
- Automatic least-privilege profile creation for future Auth users
- Forced RLS across all core tables
- Own-profile baseline read policy
- Strict Supabase database types
- Repeatable local migration execution test
- Connected Supabase acceptance query

---

## Security

- Initial accounts receive only the `parent` role.
- Client-supplied registration metadata cannot assign a privileged role.
- Authenticated users can read only their own profile.
- Core ministry and audit tables remain closed to direct client access.
- Full authorization policies remain deferred until the permission matrix is
  approved.

---

## Verification

The release passed:

- PostgreSQL migration execution
- Auth profile creation and backfill tests
- RLS and grant boundary tests
- Constraint tests
- TypeScript validation
- ESLint
- Next.js production build
- Product Owner acceptance in connected Supabase

---

## Deferred Scope

This release does not begin feature data workflows or the later security
milestone. Attendance, check-in, registration, forms, communication, reports,
and detailed authorization policies remain future work.
