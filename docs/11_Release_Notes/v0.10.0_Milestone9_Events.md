# v0.10.0 — Milestone 9 Events

**Released:** 2026-07-30

## Added

- Searchable, date-filtered event calendar
- Event creation, editing, publishing, completion, and archive retention
- Event locations, descriptions, instructions, time zones, and capacity
- Family registration for eligible linked students
- Registration windows, capacity-aware waitlists, cancellation, and guarded
  manual promotion
- Administrator registration roster
- Event-centered volunteer assignment and status management
- In-app event reminders
- Auditable event checklists

## Security and Privacy

- Managers, assigned volunteers, and families receive distinct event scopes.
- Families see only published or active events and related registrations.
- Family-student relationships control registration eligibility.
- Registration capacity and waitlist decisions occur atomically in guarded
  database functions.
- Archived events remain historical and immutable through the application.
- Direct table writes are restricted; material changes are audited.
