# Release Notes — v0.6.0

**Milestone:** 5 — Ministry Dashboard

**Date:** 2026-07-24

**Status:** Complete

## Highlights

- Added a responsive Ministry Dashboard.
- Added typed, clearly disclosed synthetic preview data.
- Added ministry summaries, events, volunteer status, registrations,
  prayer-request counts, birthdays, announcements, and quick actions.
- Added a separate privacy-minimized Family Dashboard.
- Restored the original approved project roadmap as the authoritative sequence.

## Security and Privacy

- Dashboard access continues to require `dashboard.view`.
- Administrative and family experiences are selected from the authenticated
  server-side account role.
- Family accounts do not receive ministry-wide volunteer, prayer-request, or
  birthday information.
- Confidential prayer-request content is not exposed.
- Student display labels retain the first-name/last-initial rule.
- No live or production ministry data is included.

## Verification

- Dashboard regression verification passed.
- Database, privacy, and security regression suites passed.
- TypeScript and ESLint passed.
- Next.js production build passed.
- Product Owner acceptance passed with both administrative and family accounts.

## Deferred Scope

Live data connections remain assigned to their approved feature milestones.
Member Management and all Milestone 6 behavior remain unstarted.
