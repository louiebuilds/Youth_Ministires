# v0.8.0 — Milestone 7 Volunteer Management

**Released:** 2026-07-26

## Added

- Volunteer directory and protected workspaces
- Background-check status and expiration tracking
- Certification metadata
- Skill catalog and volunteer proficiency
- Recurring weekly availability
- Assignments to existing events
- Volunteer confirmation and decline responses
- Manager assignment lifecycle controls

## Security and Privacy

- Volunteer self-access is limited to the current account.
- Family-only accounts cannot access volunteer records.
- Sensitive reports and identity documents are not stored.
- Provider references remain ministry-management-only.
- Approved changes are database-authorized and audited.
- Direct volunteer and assignment mutations are revoked.
